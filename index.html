NEXUS runs AI agents in isolated sandboxes with gated tools — and logs every action as a replayable event. When an agent breaks something, you can see exactly what it did, step by step, and replay it.

Built around the audit trail

Most agent stacks wrap a chat loop. NEXUS logs every tool call, decision, and result as an event — so replay, diff, and audit come for free.

Isolated sandbox

Filesystem and terminal access inside a Docker container. Network denied by default, resource limits enforced.

Gated tools

Every tool call routes through a permission manager. Grants are explicit, scoped, and logged.

Append-only event log

Every action gets a sequence number, timestamp, and structured data. Replayable from any point.

Replay and diff

Reproduce a failure step by step, or diff two runs event-by-event to see exactly where they diverged.

Any model, any endpoint

Works with any OpenAI-compatible endpoint. Model fallback and multi-model consensus built in.

Multi-agent cluster

Leader election, shared work queue, and task recovery when a node drops mid-run.

When an agent goes wrong,
you can prove what happened

An agent that edits files and runs commands without a trail is a liability. NEXUS writes every action to an append-only log first, then executes. The log is the source of truth — not the chat window.

  • Replay any run — reproduce or diagnose a failure from any point.

  • Diff two runs — see event-by-event where behavior diverged.

  • Audit access — which agent touched which file, under which grant.
